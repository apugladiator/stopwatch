INTERVAL CLOCK — Android-friendly stopwatch / timer / workout app

WHAT'S INCLUDED
- Stopwatch with start, pause, resume, reset, and lap splits (lap duration + total elapsed).
- Countdown timer with editable hours/minutes/seconds, start, pause, resume, reset, and laps (elapsed + remaining).
- Workout sequence builder with multiple named intervals, reorder/delete/add, duration, count-up/count-down, per-row auto-start-next, and per-row ding.
- Global seconds / tenths / hundredths display precision.
- Large high-contrast display, screen wake lock while running (where supported), local/offline caching after first load.

INSTALL ON A SAMSUNG GALAXY S25
This folder is a Progressive Web App (PWA), not a signed APK. To install it as an app icon:
1. Host the contents of this folder at an HTTPS address (for example, deploy the folder as a static site using Replit, GitHub Pages, or another static host).
2. On the Galaxy S25, open that HTTPS address in Chrome.
3. Open Chrome's ⋮ menu and choose "Install app" or "Add to Home screen".
4. Confirm. It will open in its own app window and cache for offline use after its first load.

IMPORTANT
A direct file:// open or an unhosted ZIP cannot install a PWA. An actual APK needs to be wrapped/built and signed with Android tooling. The app uses the device browser's audio and screen-wake-lock support; Android may still restrict background behavior depending on battery settings.
